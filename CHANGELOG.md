# Changelog

All notable Platformer Kit changes are recorded here. The project follows Semantic Versioning while the framework is developed as a reusable addon.

## [Unreleased]

### Added

- Celeste-style movement rules: run acceleration with over-speed friction,
  variable jump with apex half gravity, dash freeze/end speed/dash-attack
  window, no-grab wall grab/climb/stamina, wall jump/climb jump conversion,
  super/hyper/wavedash/wallbounce, global hit-stop, and platform lift caps.
  Tuning lives in `MovementProfile` and the Dash resource; no grab action is
  required.
- Optional **Celeste Momentum** Game setting (off by default): a dash preserves
  a higher pre-dash horizontal speed, and a down-diagonal ground hit applies
  the 1.2x Ultra multiplier for chained-ultra speed growth.
- Optional **Realtime Save** Game setting (off by default): captures the player
  position and velocity every two seconds and on quit, then resumes that exact
  spot next session. Death still returns to the last checkpoint.
- Debug-overlay input TAS (record/replay/save/slow motion) and a recorded
  dash-jump speed-cap demo. `Ctrl+R` records/stops, `Ctrl+P` plays/stops, and
  `Ctrl+S` saves; the original `F5`-`F12` shortcuts remain. The TAS status panel
  now lives in the HUD-space debug overlay, outside the gameplay SubViewport.
- World-centric terrain: each world now owns one authored terrain scene
  (`scenes/worlds/<world_id>/terrain.tscn`) edited with the normal Godot TileMap
  tools; **Sync Terrain** slices it into per-room runtime terrain and re-bakes the
  rooms. `tools/migrate_world_terrain.gd` migrates existing worlds (with backups),
  and a room scene previews its baked slice as an unsaved node
  (`docs/world-painting.md`).
- Draw Room: drag a chunk rectangle in the World editor to create a new
  entities-only room source (center spawn, placement, first slice bake) without
  touching the world terrain.
- Merge / Split rooms in the World editor: merge requires a rectangular union and
  moves entities, connections and the start room into a new room; split cuts one
  room on a chunk boundary and distributes entities by world position. Both use
  new room ids, back up the world and the replaced room assets, and leave the
  world terrain untouched.
- Room cell alignment: a chunk is 22.5 cells tall, so room cell rectangles now
  snap to the global grid (alternating 23 / 22-cell rows, 45 cells per two rows).
  Runtime rooms, terrain, fog, camera, light/normal/dust/shadow/crumble, fluid and
  the map all use the canonical rectangle; the world editor draws a per-block cell
  frame over the room source, and baking crops terrain outside it with entity
  warnings (`docs/world-alignment.md`).
- Numbered collectibles: `scenes/world/number_pickup.tscn` bobs, glows and is
  collected on contact; the author fills only `number`. The `Collectibles`
  autoload scans the world's baked rooms so `scenes/ui/collection_screen.tscn`
  can list every number with a collected/total badge, persisting progress per
  world in the save (`collection_toggle`, default `J`).
- Interaction prompts: the player now carries an `InteractionDetector` and a
  `PlayerInteractionController`, so `INTERACT`-mode doors and checkpoints work
  with the rebindable `interact` action. `scenes/ui/interaction_prompt.tscn`
  draws the bound glyph above the selected interactable from the HUD, outside
  the game SubViewport, and switches between keyboard and gamepad glyphs.
- Components gallery (`scenes/levels/test/components_gallery.tscn`): a two-chunk
  room with one copyable station per platform and vision component (elevator,
  conveyor, waypoint + fog occluder, falling platform, door, phantom wall,
  one-way platform). Generated by `tools/build_components_gallery.gd`, baked into
  the test world at chunk `(3, 1)`; `docs/components-gallery.md` is the copy
  guide.
- `GasBrush`: paint gas at the cursor (hold left to pour, right to shove, 1/2/3 for the channel). `paint_at()` / `blow_at()` are public, so tools and tests can drive it without faking an OS cursor.
- Gas field lab (`scenes/levels/test/gas_field_lab_runner.tscn`): a 2x2 chunk room (640x360) with corridors and one brush, i.e. the first room where the camera scrolls over the gas field. Generated by `scripts/tools/build_gas_field_lab.gd`.
- Gas solver: vorticity confinement (`Atmosphere.gas_vorticity`), so the plumes keep their curls instead of being smoothed away by the trace-back. Measured on the light lab: curl energy falls 40% over 0.8 s without it and rises 16% at 10.
- Gas detail tracer: the mist's wisp pattern is a passive scalar advected by the flow (velocity field's blue channel) instead of screen-space noise, so the texture belongs to the gas.
- Gas volume shading: the density is marched towards the key light for self-shadowing, gated by the layer's own opacity so a faint veil does not lose brightness.
- Blue-noise stylised threshold for the mist (`resources/textures/blue_noise_64.png` + `scripts/tools/bake_blue_noise.gd`): the fade is grain instead of an ordered lattice. Measured on one gas state: lattice energy 15.7% → 0.12%, mean opacity −1.1%.
- `scripts/tools/gas_diagnostic.gd`: captures the density field, the velocity/tracer field and the mist's own opacity for one gas state, with `--stipple` and `--uniform` to A/B settings against identical gas.
- `FogOccluderComponent2D`: gives any platform or solid body a sight shadow. It
  reads the host's collision footprint, answers the fog's `is_occluding()` /
  `get_world_rect()` contract, and asks the fog to rebuild only when the
  footprint crosses an 8 px cell.
- `DoorComponent2D`: a composable door leaf (size, open/closed state, collision,
  interaction, panel). It drives a `FogOccluderComponent2D` through
  `occluder_paths`, so the door itself never talks to the fog.
- `PhantomWallComponent2D`: a `TileMapLayer` that looks like terrain, never
  collides, blocks sight while it stands, and fades out when a character touches
  it. Ships as `scenes/world/phantom_wall.tscn`; state is runtime-only.
- Reusable contact/interaction checkpoints with nested respawn points and immediate persistence requests.
- Persistent generic ability pickups and a data-driven Dash definition/runtime.
- Reference-player ability loadout synchronized with Metroidvania progression and save restoration.
- Eight-way Dash: vertical and diagonal dashing, with direction deadzone, facing fallback, and 45-degree snapping (`DashAbilityDefinition.eight_directional`).
- Dash charges (`max_charges`, `refill()`): one dash per landing by default, unlimited while the game chooses to refill every frame (swimming).
- Interactive Ability Lab using the same player, pickup, and Dash resources as the reference game.
- Room backdrop plate layer (`BackdropField` + `backdrop_drift` shader) with per-scanline air shimmer behind every room.
- Screen-space CRT finish (`crt_screen` shader) that keeps bright pixels bright, with a `crt_enabled` video setting.

### Changed

- `Atmosphere.gas_cell_pixels` makes the simulation cell size a tunable (1..8 world pixels) instead of a fixed 4, and the grid ceiling went from 512 to 1024 cells per axis so a 1 px field of a 2x2 room is not silently coarsened. Measured at 1 px on a 2x2 room (640x360 = 230400 cells): 0.084 ms of CPU submit per step, no frame-time change (1.45 vs 1.55 ms uncapped), 41 MB of HDR buffers; the dye needs `gas_diffusion` re-scaled (a still puff covers 880 / 804 / 724 px2 at 4 / 2 / 1 px cells).
- The gas simulation domain no longer depends on the room: the cell is always 4 world pixels and the grid ceiling is 512 cells, so a larger room gets more cells instead of a coarser field.
- Replaced two-point platform motion with paused multi-waypoint `PING_PONG` and `CYCLE` routes.
- `scenes/world/fog_door.tscn` is assembled from `DoorComponent2D` and
  `FogOccluderComponent2D` instead of a bespoke script; the fog is now refreshed
  per crossed cell instead of per moved frame.
- Routed entity save requests through room and world runtimes instead of direct singleton access.

### Fixed

- World editor preview at high zoom: the terrain clip container was positioned at
  the world origin and sized to the viewport, so once the origin left the view its
  right/bottom edges cut the terrain off along a straight line (a rectangular bite
  that grew as you zoomed in). The containers now cover the whole preview layer and
  the terrain instance carries the world transform.
- World stacks: a saved world referenced its own `WorldStack` while the stack
  referenced the world back, and Godot's text loader cannot resolve that cycle —
  loading either file failed with "referenced non-existent resource", which took
  the world catalog and the world-select screen down with it. The stack link is
  now resolved by convention (`<world>_stack.tres` next to the world) and
  `WorldData.world_stack` is removed.
- World select: a missing/unloadable catalog fell into the untyped `[]` branch of
  a typed-array assignment, so the screen crashed instead of showing its empty
  state.
- World editor 3D stack: the **Add World** menu only listed `world_catalog.tres`,
  so a world created with **New World** (which does not register in the catalog)
  could never be layered. The menu and `add_layer` now also accept any
  `WorldData` saved in `resources/worlds/`, catalog worlds first, deduplicated by
  `world_id`.
- World editor 3D stack: **Focus All** and **Reset View** drove the hidden 2D
  canvas, so they did nothing while the 3D view was open. They now drive the
  stack view, and `WorldStack3DLayer.reset_view()` restores the default orbit and
  reframes the stack.
- The fading mist read as a regular grid of dots that resolves into vertical dashed bars on the 4x screen: the ordered dither was a lattice, not a mistake in its balance. The shipped kernel is a blue-noise tile now.
- The gas detail tracer was briefly stored in the density field's alpha channel, which a transparent viewport premultiplies, so the gas lost half its density every step (measured: field mean 0.022 to 0.0004 over 172 steps).

### Removed

- Removed `scripts/world/fog_door.gd` and its unused `door_id` export; migrate
  room overrides to the component prefab (`MIGRATION.md`).
- Removed `PingPongMotionComponent2D`; migrate authored platforms to `WaypointMotionComponent2D`.

## [0.1.0] - 2026-09-09

### Added

- Data-driven character motor, intent, sensors, movement profiles, and camera bounds.
- Composable moving, falling, rider-triggered, and conveyor platform behaviors.
- Generic interaction, stable-ID save, room, world graph, streaming, and transition contracts.
- Optional abilities, combat, Metroidvania, diagnostics, and World Editor addons.
- Independent movement, ability, combat, and Metroidvania example scenes.

### Changed

- Separated reusable framework code from reference game content.
- Moved map discovery and room authoring into optional addons.
- Defined relative, platform, and world velocity as distinct diagnostics.

### Removed

- Concrete one-way, moving, falling, and conveyor platform scripts in favor of native collision settings and composable components.
