# Controls

## Keyboard

- A / Left: move left
- D / Right: move right
- W / Up: up input
- S / Down: down input and fast fall
- Space / Z: jump

## Gamepad

- Left stick / D-Pad: movement
- South button: jump

## Debug

- F1: cycle grid overlay between hidden, 8px, and 16px.
- `[` / `]`: select a tuning field.
- `-` / `=`: adjust the selected field while the game is running.
